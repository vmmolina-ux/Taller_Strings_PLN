## Descripción del Proyecto

Este proyecto consta de dos programas en Java que aplican conceptos fundamentales de manipulación de cadenas y estructuras de datos lineales:

1. **EjercicioStrings.java:** Implementación básica de métodos de la clase String (longitud, búsquedas, transformaciones a mayúsculas/minúsculas, comparaciones y reemplazos).
2. **PipelinePLN.java:** Pipeline básico de Procesamiento del Lenguaje Natural que incluye normalización de texto, tokenización, filtrado de palabras vacías (stop words) y cálculo de frecuencia mediante ArrayList.git add .
